# ISO 14067 產品碳足跡報告編製與第三方查證合規指南

本指南基於 **ISO 14067:2018 (温室氣體 — 產品碳足跡 — 量化要求與指南)** 標準，旨在協助企業理解：
1. **如何撰寫一份合規的碳足跡報告 (CFP Study Report)**
2. **如何驗證與審查一份碳足跡報告是否合規**

---

## 第一部分：如何撰寫一份合規的產品碳足跡報告 (CFP)

根據 ISO 14067 標準，撰寫產品碳足跡報告必須遵循生命週期評估 (LCA) 方法學，並嚴格執行以下四個核心步驟：

### 步驟 1：目的與範圍界定 (Goal & Scope Definition)

這是整個碳足跡盤查的基石，必須在報告中清晰定義以下要素：
* **功能單位 (Functional Unit, FU)**：
  所有數據必須以此為基準折算與呈現。功能單位必須是可量化的，例如：「生產 1 公噸特定等級之不鏽鋼材」、「使用 1 小時之雲端運算服務」。
* **系統邊界 (System Boundary)**：
  * **搖籃到大門 (Cradle-to-Gate)**：包含從原材料開採、運輸至工廠、加工製造至成品出廠前的所有階段。適用於 B2B 的中間產品。
  * **搖籃到墳墓 (Cradle-to-Grave)**：包含原物料、製造、運輸、分銷、使用階段以及最後的廢棄處理與回收階段。適用於 B2C 的終端產品。
  * 必須繪製詳細的生命週期流程圖，明確界定哪些單元過程 (Unit Processes) 納入邊界，哪些被排除。
* **排除準則 (Cut-off Criteria)**：
  若排除某些次要的輸入或輸出（例如微量添加劑、行政人員用電），必須在報告中透明揭露。通常單一排除項目的質量或能量比重不得超過 1%，且所有排除項目的總和不得超過 5%，且排除後不能對碳足跡的結論造成實質性改變。

### 步驟 2：生命週期清查分析 (Life Cycle Inventory, LCI)

收集所有納入系統邊界內的單元過程的活動數據 (Activity Data) 與碳排係數 (Emission Factors)：
* **初級數據收集 (Primary Data)**：
  針對企業能直接控制或影響的過程（如工廠內部電錶度數、燃料耗用量、原料實際採購重量），必須優先收集現場一手量測的初級數據。時間跨度通常需連續覆蓋至少 12 個月以消除季節性變異。
* **次級數據應用 (Secondary Data)**：
  針對無法直接取得的供應鏈上游或下游數據，應引用權威資料庫（如 Ecoinvent）或各國政府官方公告的碳排係數。報告中必須說明次級數據在「技術、時間、地理」三個維度上的代表性與適用性。
* **分配原則 (Allocation)**：
  若同一製程生產多種產品（即聯產品或副產品），必須說明碳足跡如何分配。ISO 14067 要求之分配順序為：
  1. 儘量避免分配（例如藉由細分製程或擴大系統邊界）。
  2. 優先採用物理關係分配（如質量、能量比）。
  3. 其次採用經濟價值分配。

### 步驟 3：生命週期影響評估與解釋 (LCIA & Interpretation)

* **計算全球暖化潛勢 (GWP 100)**：
  必須採用聯合國政府間氣候變化專門委員會 (IPCC) 最新公佈的 100 年 GWP 係數，將盤查到的所有溫室氣體（包含 CO2, CH4, N2O, HFCs, PFCs, SF6, NF3 等）轉化為二氧化碳當量 (CO2e)。
* **化石碳與生物碳的區分**：
  報告中必須將化石燃燒產生的碳排放 (Fossil Carbon) 與生物來源（如木材、生質能）的碳排放與清除 (Biogenic Carbon) 分開列計。
* **土地利用變化 (Land Use Change, LUC) 排放**：
  若原料生產涉及森林砍伐或土地變更，必須將因此產生的碳排放納入計算。
* **敏感度與不確定性分析**：
  評估關鍵假設（如能源結構選擇、分配方法）若變更時對碳足跡結果的波動影響，以確保報告的穩健性。

### 步驟 4：報告撰寫與溫室氣體聲明

合規的報告書必須包含以下核心結構，且不得有任何刻意誤導的陳述：
1. **報告概述**：盤查發起者、編製者、報告日期、遵循標準。
2. **產品描述與功能單位**。
3. **系統邊界及流程圖**（詳列納入與排除之單元過程）。
4. **清查數據清單與數據品質評估**。
5. **碳足跡計算結果**（以 CO2e/功能單位 呈現，區分不同生命週期階段）。
6. **分配方法與敏感度分析說明**。
7. **限制聲明**（例如：本報告是否符合 B2C 比較性宣稱）。

## 第二部分：如何驗證產品碳足跡報告是否合規 (第三方查證)

驗證（或稱查證，Verification）是查證機構（例如 SGS, BSI, TÜV 等國際公正第三方機構）根據 **ISO 14064-3** 與 **ISO 17029** 標準，對產品碳足跡報告進行的獨立審查過程。

合規驗證的核心檢驗流程與關鍵要求如下：

### 1. 策略分析與範圍查驗
* **邊界審查**：查證官第一步會審查企業申報的「系統邊界」是否完整，是否有將高碳排製程刻意排除（即櫻桃效應/粉飾邊界）。
* **PCR 對照**：若該產品有適用的產品類別規則 (Product Category Rules, PCR)，查證官會檢查報告是否嚴格遵循 PCR 中的特定計算規則，以確保該產品未來與同業進行比較時的公正性。

### 2. 數據流與審計軌跡 (Audit Trail) 的反向追蹤
查證最核心的工作是確保報告中數據的**真實性與可回溯性**。查證官會採取「反向追蹤」：
* **原始憑證核對**：抽查報告中的數據（例如製程用電 50,000 kWh），要求企業出示該盤查區間內的「台電電費單」、「發票」或「儀器校正量測紀錄」。
* **數據流對接**：核對原始憑證數據如何彙整至 Excel 或碳盤查系統，系統又如何乘以碳排係數得到最終碳排。任何沒有原始憑證支撐的數據，查證官皆不予採信。
* **係數版本校對**：審查所引用的碳排係數是否為最新、最適用的版本（如環境部最新版碳足跡係數或 Ecoinvent 資料庫）。

### 3. 分配方法與恆等式平衡檢驗
* **質量與經濟流核算**：如果製程涉及聯產品，查證官會重新計算分配公式，確保分配比例（無論是質量比、能量比或 wirtschaftliche allocation）完全正確，且副產品的碳排沒有在其他地方被「重複計算」(Double Counting) 或「憑空消失」。
* **物料平衡 check**：檢驗原物料進貨量、產出成品量、以及廢棄物量是否符合守恆定律。

### 4. 實質性偏差 (Materiality Level) 與合理保證
* **偏差計算**：在稽核過程中發現的所有數據誤差、漏算、錯估的百分比總和，即為「實質性偏差」。
* **合格閥值**：根據 ISO 標準與驗證實務，**實質性偏差必須小於 5%**。若查證官發現累計數據誤差超過 5%，該報告將被判定為「不合規」，企業必須修正盤查數據後重新申請稽核。
* **保證等級**：確認查證結果是達到「合理保證等級」(Reasonable Assurance，高信賴度) 還是「有限保證等級」(Limited Assurance，較低信賴度)。

### 5. 查證決策與聲明書核發
查證官完成現場稽核後會編製查證報告，提交給查證機構內部的「技術審查人」(Technical Reviewer) 進行二次獨立審查。確認無誤後，查證機構才會正式核發 **ISO 14067 產品碳足跡查證聲明書**。
